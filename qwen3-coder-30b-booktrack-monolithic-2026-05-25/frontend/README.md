# Book Tracker Frontend

This is a React frontend for the Book Tracker application built with Vite.

## Features
- Add books with title, author, and status
- View all books in a responsive grid
- Update book status (To Read, Reading, Done)
- Delete books

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. The app will be available at http://localhost:3000

## Project Structure
- `src/App.jsx` - Main application component
- `src/App.css` - Styles for the application
- `src/main.jsx` - Entry point
