# BookTrack Frontend

Frontend per BookTrack, un'app per tracciare i libri che leggo.

## Tecnologie

- React
- Vite
- Fetch API per le chiamate HTTP

## Avvio

Per eseguire il frontend:

```bash
# Installa le dipendenze
npm install

# Esegui l'app in modalità sviluppo
npm run dev
```

## Funzionalità

- Aggiunta di nuovi libri con titolo, autore e status
- Visualizzazione della lista dei libri
- Aggiornamento dello status dei libri
- Eliminazione dei libri
- Gestione degli errori e stato di caricamento
